## 🔄 Этап 2: Расширенные типы задач (В разработке)

### Приоритет: Высокий
**Срок:** Q1 2025

### Задачи

#### 2.1 Multiple Choice Widget
**Описание:** Вопросы с несколькими правильными ответами

**Функционал:**
- Чекбоксы вместо radio buttons
- Проверка на полное совпадение выбора
- Визуальная обратная связь для каждого варианта
- Подсчет частичных баллов (опционально)

**Payload структура:**
```json
{
  "question": "string",
  "options": [
    {
      "id": "string",
      "text": "string",
      "isCorrect": boolean
    }
  ],
  "requireAllCorrect": boolean,
  "partialCredit": boolean
}
```

#### 2.2 True/False Widget
**Описание:** Простые вопросы верно/неверно

**Функционал:**
- Две большие кнопки: Верно / Неверно
- Объяснение после ответа
- Поддержка изображений в вопросе

**Payload структура:**
```json
{
  "statement": "string",
  "isTrue": boolean,
  "explanation": "string",
  "imageUrl": "string (optional)"
}
```

#### 2.3 Match Pairs Widget
**Описание:** Соединение связанных элементов

**Функционал:**
- Drag & drop интерфейс
- Две колонки элементов
- Визуальные связи (линии)
- Проверка всех пар одновременно

**Payload структура:**
```json
{
  "instruction": "string",
  "leftItems": [
    {"id": "string", "text": "string", "imageUrl": "string (optional)"}
  ],
  "rightItems": [
    {"id": "string", "text": "string", "imageUrl": "string (optional)"}
  ],
  "correctPairs": [
    {"leftId": "string", "rightId": "string"}
  ]
}
```

#### 2.4 Drag and Drop Sequence Widget
**Описание:** Упорядочивание элементов в правильной последовательности

**Функционал:**
- ReorderableListView
- Drag handles для перемещения
- Визуальные индикаторы порядка
- Проверка точной последовательности

**Payload структура:**
```json
{
  "instruction": "string",
  "items": [
    {
      "id": "string",
      "text": "string",
      "correctPosition": number
    }
  ],
  "showPositionNumbers": boolean
}
```

#### 2.5 Text Input Widget
**Описание:** Короткие текстовые ответы

**Функционал:**
- Поле ввода текста
- Валидация ответа (точное совпадение / частичное)
- Игнорирование регистра и пробелов
- Список допустимых вариантов ответа

**Payload структура:**
```json
{
  "question": "string",
  "acceptedAnswers": ["string"],
  "caseSensitive": boolean,
  "trimWhitespace": boolean,
  "maxLength": number
}
```

## 📝 Примечания к разработке

### Принципы разработки
1. **Mobile-first:** Приоритет на мобильный опыт

- 100% null safety
