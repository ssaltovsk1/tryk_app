# ЧАСТЬ 1: ОБЗОР ИГРЫ

## 1.1 Концепция

### Высокоуровневое описание
"АнтиОбман" — мобильная образовательная RPG, обучающая детей 6-10 лет критическому мышлению через игровые механики. Игрок исследует мир, взаимодействует с NPC, принимает решения и учится на последствиях своих выборов.

### Ключевая идея
**Не "запомни правила", а "научись думать".**

Игра развивает 6 базовых навыков критического мышления:

```
┌─────────────────────────────────────────────────────────────────────┐
│                 6 СТОЛПОВ КРИТИЧЕСКОГО МЫШЛЕНИЯ                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  👁️ ЗАМЕЧАТЬ РАЗЛИЧИЯ                                               │
│     Видеть детали, находить несоответствия                          │
│                                                                     │
│  ❓ ЗАДАВАТЬ ВОПРОСЫ                                                 │
│     Не принимать информацию без проверки                            │
│                                                                     │
│  💬 ОБЪЯСНЯТЬ СВОИ ДЕЙСТВИЯ                                         │
│     Осознавать и формулировать причины выбора                       │
│                                                                     │
│  ⚖️ СРАВНИВАТЬ                                                       │
│     Анализировать варианты, искать лучший                           │
│                                                                     │
│  🎯 ПРИНИМАТЬ РЕШЕНИЯ                                                │
│     Делать осознанный выбор на основе анализа                       │
│                                                                     │
│  🔗 ПОНИМАТЬ ПОСЛЕДСТВИЯ                                             │
│     Видеть связь причина → следствие                                │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Уникальное торговое предложение (USP)
1. **Навыки на всю жизнь** — учим думать, а не запоминать
2. **Безопасная среда для ошибок** — ошибки = обучение, не наказание
3. **Адаптивность** — игра подстраивается под уровень ребёнка
4. **ИИ-ментор** — персональный помощник для каждого игрока
5. **Измеримый прогресс** — родители видят развитие навыков

# ЧАСТЬ 2: СИСТЕМА НАВЫКОВ КРИТИЧЕСКОГО МЫШЛЕНИЯ

## 2.1 Шесть базовых навыков

Каждый навык — это ветка развития, которая прокачивается через игровые ситуации.

### 👁️ ЗАМЕЧАТЬ РАЗЛИЧИЯ (Observation)

**Описание:** Способность видеть детали, находить несоответствия, замечать изменения.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Найди отличие"                                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ Ситуация: NPC показывает "официальное письмо"                       │
│                                                                     │
│ ┌─────────────────────┐    ┌─────────────────────┐                  │
│ │ Настоящее письмо    │    │ Фейковое письмо     │                  │
│ │                     │    │                     │                  │
│ │ 🏛️ Логотип школы    │    │ 🏛️ Логотип (кривой) │ ← отличие       │
│ │ Директор: Иванова   │    │ Директор: Иванов    │ ← отличие       │
│ │ Подпись ✓           │    │ Подпись (нет)       │ ← отличие       │
│ └─────────────────────┘    └─────────────────────┘                  │
│                                                                     │
│ Игрок должен: найти и отметить различия                             │
│ Награда: +XP к навыку "Наблюдательность"                            │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Сравнение "настоящего" и "поддельного" документа
- Поиск несоответствий в рассказе NPC
- Замечать изменения в окружении (было/стало)
- Находить скрытые детали на сцене

**Уровни навыка:**
| Уровень | Способность |
|---------|-------------|
| 1-25% | Подсветка очевидных различий |
| 26-50% | Подсказка "здесь что-то не так" |
| 51-75% | Видит мелкие несоответствия |
| 76-100% | Автоматически замечает все красные флаги |

---

### ❓ ЗАДАВАТЬ ВОПРОСЫ (Questioning)

**Описание:** Способность не принимать информацию на веру, уточнять, проверять.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Допрос"                                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ NPC: "Я друг твоего папы! Он попросил меня забрать тебя."           │
│                                                                     │
│ Стандартные ответы:          Вопросы (разблокируются навыком):      │
│ ┌─────────────────────┐      ┌─────────────────────────────────┐    │
│ │ • "Хорошо, идём"    │      │ • "Как зовут моего папу?"       │    │
│ │ • "Нет"             │      │ • "Где вы познакомились?"       │    │
│ │ • "Спросить ментора"│      │ • "Почему папа сам не пришёл?"  │    │
│ └─────────────────────┘      │ • "Можно позвонить папе?"       │    │
│                              └─────────────────────────────────┘    │
│                                                                     │
│ Каждый правильный вопрос раскрывает ложь NPC                        │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Уточнение деталей у подозрительных NPC
- Проверка "слишком хороших" предложений
- Выяснение мотивов ("Зачем тебе это?")
- Запрос доказательств ("Покажи документ")

**Банк вопросов (примеры):**
```
Категория "Проверка личности":
- Как тебя зовут?
- Откуда ты меня знаешь?
- Кто тебя послал?

Категория "Проверка истории":
- Почему именно сейчас?
- А что будет, если я откажусь?
- Можно я сначала спрошу у родителей?

Категория "Проверка предложения":
- Почему это бесплатно?
- В чём подвох?
- Почему ты выбрал именно меня?
```

### 💬 ОБЪЯСНЯТЬ СВОИ ДЕЙСТВИЯ (Articulation)

**Описание:** Способность осознавать и формулировать причины своего выбора.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Почему ты так решил?"                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ После каждого важного выбора Совёнок спрашивает:                    │
│                                                                     │
│ 🦉 "Ты отказался дать пароль. Почему?"                              │
│                                                                     │
│ Варианты объяснения:                                                │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │ 😐 "Не знаю, просто так"                     → 0 XP             │ │
│ │ 🤔 "Мне показалось подозрительным"           → +10 XP           │ │
│ │ 💡 "Он незнакомец, а пароли секретные"       → +20 XP           │ │
│ │ 🌟 "Незнакомец + торопил + просил секрет     → +30 XP           │ │
│ │     = три красных флага"                                        │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│                                                                     │
│ Чем точнее объяснение, тем больше награда                           │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Рефлексия после выбора (почему так?)
- Обучение других персонажей (младших NPC)
- Дневник решений (журнал игрока)
- Дебаты с NPC (защита своей позиции)

### ⚖️ СРАВНИВАТЬ (Comparison)

**Описание:** Способность анализировать варианты, видеть плюсы и минусы.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Весы решений"                                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ Торговец предлагает обмен. Игрок видит "весы":                      │
│                                                                     │
│         ОТДАЮ                    ПОЛУЧАЮ                            │
│     ┌───────────┐            ┌───────────┐                          │
│     │ 🗡️ Меч     │            │ 💎 10     │                          │
│     │ (редкий)  │            │ алмазов   │                          │
│     │           │            │           │                          │
│     │ Сила: +20 │            │ Можно     │                          │
│     │ Уникальный│            │ купить:   │                          │
│     │           │            │ 2 зелья   │                          │
│     └───────────┘            └───────────┘                          │
│           ⚖️                                                         │
│     ┌─────────────────────────────────────┐                         │
│     │ ❓ Это выгодный обмен?              │                         │
│     │                                     │                         │
│     │ [Да, выгодно]  [Нет, невыгодно]     │                         │
│     └─────────────────────────────────────┘                         │
│                                                                     │
│ Правильный анализ = бонус XP                                        │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Оценка предложений торговцев
- Выбор между двумя путями (плюсы/минусы)
- Сравнение показаний разных NPC
- Анализ "что было бы, если..."

### 🎯 ПРИНИМАТЬ РЕШЕНИЯ (Decision Making)

**Описание:** Способность делать осознанный выбор на основе собранной информации.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Момент выбора"                                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ После сбора информации — финальное решение:                         │
│                                                                     │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │                    📋 ЧТО ТЫ УЗНАЛ:                              │ │
│ │                                                                 │ │
│ │  ✓ Незнакомец не знает имя твоего папы                          │ │
│ │  ✓ Он торопит тебя                                              │ │
│ │  ✓ Не может показать документы                                  │ │
│ │  ✓ Твой папа не предупреждал о визите                           │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│                                                                     │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │                    🎯 ТВОЁ РЕШЕНИЕ:                              │ │
│ │                                                                 │ │
│ │  [🚶 Пойти с ним]     [🏃 Убежать]     [📞 Позвать взрослого]   │ │
│ │                                                                 │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│                                                                     │
│ Игра оценивает: соответствует ли решение собранным фактам?          │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Финальный выбор после расследования
- Выбор под давлением времени
- Решения с неполной информацией
- Групповые решения (с другими NPC)

**Критерии оценки решения:**
| Критерий | Баллы |
|----------|-------|
| Решение соответствует фактам | +20 |
| Учтены все красные флаги | +15 |
| Не поддался давлению | +10 |
| Попросил помощь, когда нужно | +10 |
| Решение под эмоциями (страх/жадность) | -10 |

### 🔗 ПОНИМАТЬ ПОСЛЕДСТВИЯ (Cause & Effect)

**Описание:** Способность видеть связь между действием и результатом, предвидеть исходы.

**Как тренируется в игре:**
```
┌─────────────────────────────────────────────────────────────────────┐
│ МЕХАНИКА: "Что будет, если..."                                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│ Перед важным выбором игрок может "заглянуть в будущее":             │
│                                                                     │
│ 🦉 Совёнок: "Давай подумаем, что может произойти?"                  │
│                                                                     │
│ Выбор: "Дать пароль незнакомцу"                                     │
│                                                                     │
│ ┌─────────────────────────────────────────────────────────────────┐ │
│ │              ВОЗМОЖНЫЕ ПОСЛЕДСТВИЯ:                             │ │
│ │                                                                 │ │
│ │  😊 Если он честный:                                            │ │
│ │     → Он поможет (маловероятно)                                 │ │
│ │                                                                 │ │
│ │  😰 Если он мошенник:                                           │ │
│ │     → Он украдёт мои вещи                                       │ │
│ │     → Я потеряю доступ к шкафчику                               │ │
│ │     → Мне будет обидно                                          │ │
│ │                                                                 │ │
│ │  ⚖️ Риск: ВЫСОКИЙ                                                │ │
│ └─────────────────────────────────────────────────────────────────┘ │
│                                                                     │
│ После выбора — показываем реальные последствия                      │
│ Сравниваем: "Помнишь, что мы предсказывали?"                        │
└─────────────────────────────────────────────────────────────────────┘
```

**Игровые ситуации:**
- Предсказание исходов перед выбором
- Flashforward — короткие видения будущего
- Анализ прошлых решений ("Из-за чего это случилось?")
- Цепочки событий (A → B → C)

**Механика "Дерево последствий":**
```
                        Выбор: Дал пароль
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
        Немедленно:                     Через день:
        Незнакомец                      Шкафчик пуст
        улыбается                             │
              │                               ▼
              │                         Через неделю:
              │                         Другие дети
              │                         узнали, дразнят
              │                               │
              └───────────────┬───────────────┘
                              ▼
                        Урок: Одно решение
                        влияет на многое
```

# ЧАСТЬ 3: ИГРОВЫЕ МЕХАНИКИ

### Архетипы мошенников

```
1. "ПОМОЩНИК"
   Маскировка: Представитель власти
   Тактика: Авторитет + срочность
   Красные флаги: Нет документов, торопит, просит пароль
   
2. "ДРУГ"
   Маскировка: Новый знакомый
   Тактика: Быстрое доверие + просьбы
   Красные флаги: Слишком быстро, просит ценное, секретность
   
3. "БЛАГОДЕТЕЛЬ"
   Маскировка: Щедрый даритель
   Тактика: Бесплатные подарки → просьба в ответ
   Красные флаги: Слишком хорошо, требует данные
   
4. "ЖЕРТВА"
   Маскировка: Нуждающийся в помощи
   Тактика: Жалость → просьба о помощи
   Красные флаги: Странные просьбы, давление на эмоции
   
5. "ПРОДАВЕЦ"
   Маскировка: Честный торговец
   Тактика: Выгодные предложения → обман
   Красные флаги: Нереальная выгода, торопит, скрытые условия
```
