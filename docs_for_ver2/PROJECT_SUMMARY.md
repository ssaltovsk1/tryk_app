## 1. ТЕХНИЧЕСКОЕ ЗАДАНИЕ

### 1.1 Концепция
Мобильная образовательная RPG с пиксельной графикой (стиль Soul Knight / Terraria) для обучения детей критическому мышлению и противодействию мошенникам.

### 1.2 Целевая аудитория
- **Возраст:** 6-10 лет
- **Платформы:** iOS + Android
- **Модель:** Бесплатная (с возможной монетизацией в будущем)

### 1.3 Основные функции

| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Открытый мир | Игрок ходит по локациям, взаимодействует с NPC | Высокий |
| Система диалогов | Выборы, последствия, обучающие сценарии | Высокий |
| ИИ-ментор | Помощник "Совёнок" для объяснений и поддержки | Высокий |
| Древо умений | Прогресс обучения, разветвлённый сюжет | Высокий |
| Видео-контент | Открытие в системном браузере/плеере | Средний |
| Мультиплеер | Текстовый чат с модерацией (будущее) | Низкий |
| Модульный контент | Подгрузка уровней/героев без обновления ядра | Высокий |

### 1.4 Ключевые особенности
- **НЕТ боевой системы** — только общение, обучение, выборы
- **Обучение через игру** — сценарии мошенничества адаптированы для детей
- **Серверная архитектура** — контент подгружается с сервера
- **Безопасность детей** — COPPA compliance, модерация, фильтры

## 2. ОБЩИЕ ДАННЫЕ ПРОЕКТА

### 2.1 Технологический стек (рекомендованный)

```
КЛИЕНТ:
├── Движок: Unity 2022 LTS
├── Язык: C#
├── Контент: Unity Addressables
└── Вид камеры: Top-down (рекомендован)

СЕРВЕР:
├── Backend: Node.js + NestJS
├── База данных: PostgreSQL + Redis
├── Real-time: Socket.IO
├── AI: Claude API (primary) / OpenAI (fallback)
└── Хостинг: AWS (ECS, RDS, S3, CloudFront)

ИНФРАСТРУКТУРА:
├── Auth: Firebase Authentication
├── CDN: AWS CloudFront
├── Storage: AWS S3
└── CI/CD: Unity Cloud Build + GitHub Actions
```

### 2.2 Почему Unity?
- Лучшая система модульной загрузки (Addressables)
- Кроссплатформенность из коробки
- Огромное сообщество и документация
- Бесплатен до $200k дохода

### 2.3 Сравнение движков

| Критерий | Unity | Godot | Unreal |
|----------|-------|-------|--------|
| 2D-игры | ✅ Отлично | ✅ Отлично | ⚠️ Избыточен |
| Кроссплатформа | ✅ Из коробки | ✅ Есть | ✅ Есть |
| Модульная загрузка | ✅ Addressables | ⚠️ Сложнее | ⚠️ Сложнее |
| Мультиплеер | ✅ Много решений | ⚠️ Меньше | ✅ Есть |
| Документация | ✅ Огромная | ⚠️ Растёт | ✅ Большая |

### 2.4 Вид камеры: Top-down vs Side-scroller

**Top-down (РЕКОМЕНДОВАН):**
- Проще навигация по городу/локациям
- Лучше для социальных/диалоговых игр
- Легче делать интерьеры

**Side-scroller:**
- Лучше для платформинга
- Проще анимации
- Сложнее "ходить по городу"

## 3. ГЕЙМПЛЕЙ И МЕХАНИКИ

### 3.1 Основной цикл
```
Игрок ходит по миру
       ↓
Встречает NPC (некоторые — мошенники)
       ↓
Диалоги с выборами
       ↓
Последствия выбора (потеря/награда)
       ↓
Обучение от ИИ-ментора
       ↓
Прокачка навыков в древе умений
       ↓
Новые уровни и сценарии
```

### 3.2 Типы сценариев мошенничества (для детей 6-10)

| Сценарий | Пример в игре |
|----------|---------------|
| "Бесплатный приз" | NPC: "Ты выиграл! Скажи пароль от сундука" |
| Фейковый друг | Новый "друг" просит одолжить редкий предмет |
| Давление | "Решай быстро! Предложение исчезнет!" |
| Ложный авторитет | "Я от администрации, дай доступ к дому" |
| Слишком хорошо | "Меняю твой камень на 100 алмазов" |
| Фишинг | Письмо: "Аккаунт взломают, перейди по ссылке" |

### 3.3 Древо умений (ветки)

```
                    🎓 Мастер безопасности
                           │
          ┌────────────────┼────────────────┐
          │                │                │
    🔍 Распознавание  💪 Устойчивость  🗣️ Коммуникация
          │                │                │
    ┌─────┴─────┐    ┌─────┴─────┐    ┌─────┴─────┐
  Фейки    Манипуляции  Давление  Отказ   Помощь  Проверка
```

Каждый навык даёт бонусы: подсказки в диалогах, подсветка "красных флагов" и т.д.

### 3.4 ИИ-ментор "Совёнок"

**Роль:**
- Всегда доступен для вопросов
- Объясняет ошибки без критики
- Хвалит за правильные решения
- Адаптируется под уровень ребёнка

**Безопасность:**
- Двойная фильтрация (вход + выход)
- Строгий системный промпт
- Fallback на заготовленные ответы
- Лимит сообщений в день

## 4. ЛОГ ОБСУЖДЕНИЯ (Q&A)

### Вопрос 1: Платформа и движок?
**Ответ:** Unity рекомендован — лучшая система модульной загрузки (Addressables), кроссплатформа, большое сообщество.

### Вопрос 2: Обе платформы (iOS + Android)?
**Ответ:** Да, Unity поддерживает обе из коробки.

### Вопрос 3: Оффлайн или сервер?
**Ответ:** Серверная архитектура — контент подгружается с сервера. Позволяет:
- Маленький размер APK
- Обновления без релиза в сторы
- Общение игроков (в будущем)
- Общение с ИИ

### Вопрос 4: Контент-паки бесплатные?
**Ответ:** Да, бесплатные обновления.

### Вопрос 5: Локально или скачивать паки?
**Ответ:** Скачивать с сервера — меньше размер приложения, проще обновлять контент.

### Вопрос 6: Top-down или Side-scroller?
**Ответ:** Top-down рекомендован для социальной/образовательной игры без платформинга.

### Вопрос 7: Боевая система?
**Ответ:** НЕТ боя. Только:
- Ходьба и исследование
- Диалоги и выборы
- Обучение и "обманы" от NPC

### Вопрос 8: Прогрессия?
**Ответ:** Древо умений с разветвлённым сюжетом-обучением.

### Вопрос 9: Видео в игре?
**Ответ:** Открытие в системном браузере/плеере:
```csharp
Application.OpenURL("https://youtube.com/watch?v=xxxxx");
```
Просто, работает везде, нет проблем с политиками.

### Вопрос 10: Тематика обучения?
**Ответ:** Критическое мышление и противодействие мошенникам.

### Вопрос 11: Как проверяется обучение?
**Ответ:** Практические задания в игре + оценка ИИ-ментором.

### Вопрос 12: "Обманы" — что это?
**Ответ:** NPC-мошенники пытаются обмануть игрока в игре (выманить предметы, пароли). Учит критическому мышлению.

### Вопрос 13: Возрастная группа?
**Ответ:** 6-10 лет. Простой язык, яркий UI, эмодзи.

### Вопрос 14: Роль ИИ?
**Ответ:** Ментор, учитель, практик общения. Всегда рядом, помогает разобраться.

### Вопрос 15: Модерация ИИ?
**Ответ:** Ручная + автоматический фильтр на входе и выходе.

### Вопрос 16: Мультиплеер — что делают вместе?
**Ответ:** Пока не определено. Текстовый чат с модерацией в будущем.

## 6. БЕЗОПАСНОСТЬ ДЕТЕЙ

### 6.1 COPPA Compliance
- Email родителя обязателен при регистрации
- Подтверждение родителем
- Минимальные личные данные
- Родительский контроль

### 6.2 Модерация чата (будущее)
- Только готовые фразы ИЛИ модерируемый текст
- AI-фильтр всех сообщений
- Блокировка личных данных
- Репорт система

### 6.3 Безопасность ИИ
- Строгий системный промпт
- Двойная фильтрация (вход + выход)
- Лимит сообщений
- Логирование для review
- Fallback на безопасные заготовки

## 7. РОАДМАП

### MVP (3-4 месяца)
```
Месяц 1: Unity setup, движение персонажа, прототип диалогов, базовый UI
Месяц 2: Квесты, тестовый уровень, базовый AI-ментор, backend MVP
Месяц 3: Древо умений, 3-5 сценариев, полировка UI/UX, тесты с детьми
Месяц 4: Баги, оптимизация, подготовка к релизу, soft launch
```

### Post-MVP (6-12 месяцев)
- Система контент-паков (Addressables)
- Больше уровней и сценариев
- Мультиплеер (чат)
- Видео-интеграция
- Родительский кабинет
- Аналитика обучения
- Интеграция со школами
