**Дата:** 2025-12-03
**Версия:** 1.0

---

## 1. КОНЦЕПЦИЯ РАЗВЕТВЛЕНИЯ

### 1.1 Принцип

```
                         Выбор игрока
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
         Путь A          Путь B          Путь C
        (ошибка)        (частично)      (успех)
              │               │               │
              ▼               ▼               ▼
         Обучение →     Подсказка →      Награда
              │               │               │
              └───────────────┼───────────────┘
                              ▼
                      Следующий этап
                    (адаптированный)
```

### 1.2 Ключевые особенности

- **Нет "game over"** — ошибки ведут к обучению, не к проигрышу
- **Адаптивность** — сюжет подстраивается под уровень игрока
- **Накопление опыта** — выборы влияют на доступные опции в будущем
- **Множественные пути к цели** — нет единственно правильного прохождения

│                    │              │ • ⭐ "Почему ты     │

│                    │              │                     │

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Навык 0-25%:    Нет подсказок
Навык 25-50%:   Подсказка после ошибки
Навык 50-75%:   Подсказка перед выбором (слабая)
Навык 75-100%:  Подсказка перед выбором (сильная) + бонусные опции
